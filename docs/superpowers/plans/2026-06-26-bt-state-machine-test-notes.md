## 待实机验证

### 1. 高频 `?` 测试

- **方法**：连接蓝牙后，从上位机以 100Hz 发送 `?`，持续 30 秒。
- **通过标准**：
  - 面板电机不出现微动。
  - 串口日志中 `[BT-EOL gap=...]` 不异常增大。
- **状态**：待实机验证

### 2. 断连重连清理测试

- **方法**：
  1. 连接蓝牙。
  2. 发送半条指令（如 `G0 X10` 但不回车）。
  3. 强制断开蓝牙。
  4. 重新连接。
  5. 发送 `$I` 或 `?`。
- **通过标准**：不执行旧的 `G0 X10`，不触发自动换纸。
- **状态**：待实机验证

### 3. `Bf` 字段验证

- **方法**：连接后发送 `?`，观察返回状态行。
- **通过标准**：`Bf` 第一个数字接近 `client_buffer_available_for_write(CLIENT_BT)`（约 0–2048），而非固定 512 附近。
- **状态**：待实机验证

### 4. 长期压力测试

- **方法**：连续 100+ 页写字 + 上位机高频状态查询。
- **通过标准**：不停止、不丢步、不换纸异常。
- **状态**：待实机验证
